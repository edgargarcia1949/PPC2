# ppc2 - Multi-featured Pretty Printable Calendar

Multi-featured calendar app that is truly like no other.
Built with Python and Pygame.

![ppc2 Screenshot](screenshot.png)
![ppc2 Screenshot](screenshot2.png)

## Features
* 3 different window sizes, 6 custom highlight color schemes and
   Dark/Light modes
   
* US and European week start options

* Automatic holiday loading

* Standalone Linux AppImage executable

## Downloads & Installation

Select the package corresponding to your operating system:

### 🪟 Windows
- 💾 **[Download ppc2ForWindows.zip (Direct Link)](https://github.com/edgargarcia1949/PPC2/ppc2ForWindows)**
- **To Run:** Extract the `.zip` archive completely, open the folder, and double-click `ppc2.exe`. *(If Windows SmartScreen warns you, click "More info" -> "Run anyway".)*

### 🍏 macOS
- 💾 **[Download ppc2ForMac.zip (Direct Link)](https://github.com/edgargarcia1949/PPC2/ppc2ForMac)**
- **To Run:** Unzip the package and run the `ppc2.app` bundle.

### 🐧 Linux
- 💾 **[Download ppc2-x86_64.AppImage (Direct Link)](https://github.com/edgargarcia1949/ppc2-x86_64.AppImage)**
- **To Run:** Make the AppImage executable and run it via terminal or file manager:
  ```bash
  chmod +x ppc2-x86_64.AppImage
  ./ppc2-x86_64.AppImage
  ```
