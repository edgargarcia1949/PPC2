ppc2 readme

control + h puts all this help on the screen

This app is a features-rich calendar app that uses:

control + - for smaller calendar (3 sizes)
control + = for larger calendar
control + c to change highlight color (6 colors)
control + d for dark mode toggle
control + e for european-style calendar toggle
control + h for built-in help screen toggle
control + q to quit
control + p sends full size light-mode calendar to default printer
control + s sends screenshot named "screenshot+date+time" to Pictures directory

When checking my Windows version, the screenshot was placed in the current directory
where the help file said it should be and I find that okay.

right arrow advances 1 month
left arrow goes back 1 month
up arrow advances 1 year
down arrow goes back 1 year

shift + up arrow advances 10 years
shift + down arrow goes back 10 years
shift + right arrow resets to current month and year

This app also gets holidays from the years 2026 to 2034 from 20xxholidays.json files which are editable if you wish to add your own holidays or remove some of the ones I have chosen.
Just be careful with brackets and commas and quotation marks or the calendar will have no holidays for that month.

Also you can enter your own events from the keyboard just like a spreadsheet.  Click on the date and enter your event and hitting Enter stores the event in a file called personal_events.json located in a safe place on your storage drive.  Personal events can be deleted by clicking on the date, hitting delete followed by the Enter key. On a Mac, the delete key is used as a backspace key so if you wish
to delete an event, you have to press the delete key until the event is gone.

Note that holiday events gotten from local json files can't be deleted.  You must edit the
particular file you wish to modify using a text editor or other app that does not add invisible characters that may cause problems.

Why did I do those last 3 items.  With only a few keystrokes you can
go back in time to when you were born to see what day you were born on.
I was born on a Friday and my wife was born on a Sunday and that is
how I knew my calendar logic was accurate.
